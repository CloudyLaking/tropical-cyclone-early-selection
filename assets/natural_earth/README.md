# Natural Earth coastline

These five files provide the Natural Earth 1:50m coastline for offline rendering of Figure S15: `ne_50m_coastline.shp`, `.shx`, `.dbf`, `.prj`, and `.cpg`.

Natural Earth vector and raster map data are public domain. Source and terms: https://www.naturalearthdata.com/about/terms-of-use/ (checked 19 October 2026).
